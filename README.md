# Site da Igreja

Site institucional desenvolvido para apresentar informações, atividades e projetos sociais de uma igreja.

## Páginas

- `index.html` — Página inicial
- `cultos-eventos.html` — Cultos e eventos
- `destaques.html` — Destaques
- `projetos-sociais.html` — Projetos sociais
- `quem-somos.html` — Quem somos

## Tecnologias

- HTML

## Como visualizar

Abra o arquivo `index.html` em seu navegador.
